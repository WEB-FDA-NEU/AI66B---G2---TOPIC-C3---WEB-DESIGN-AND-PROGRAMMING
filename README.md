# Homestay Booking Website

## 1. Project Description

The Homestay Booking Website is an online platform that allows customers to search for accommodations, view homestay information, check room availability, and make reservations online.

The website is designed for two main types of users:

- **Customers:** Search for homestays, check room availability, make reservations, and manage their bookings.
- **Hosts:** Manage homestays, rooms, prices, availability, and customer reservations.

The main goal of this project is to provide a convenient and user-friendly platform for customers to find suitable accommodations while helping hosts manage their properties and bookings efficiently.

## 2. Main Features

### Customer Features

- Register a new account
- Log in and log out
- Browse available homestays
- Search for homestays
- Filter accommodations by different criteria
- View detailed homestay information
- Check room availability
- Select check-in and check-out dates
- Make a room reservation
- Calculate the total booking cost based on the number of nights
- View booking history
- Cancel reservations
- Manage personal information

### Host Features

- Host login
- Add new homestays
- Edit homestay information
- Delete homestays
- Add and manage rooms
- Update room prices
- Manage room availability
- View customer reservations
- Manage booking information

### System Features

- Check room availability
- Prevent duplicate or overlapping bookings
- Automatically calculate the total booking price
- Manage customer and host accounts
- Role-based access control
- Validate booking information and dates
- Manage reservation data

## 4. Main User Flow

### Customer Flow

Home Page  
→ Search for a Homestay  
→ View Homestay List  
→ View Homestay Details  
→ Select Check-in / Check-out Dates  
→ Check Room Availability  
→ Select Room  
→ Make a Booking  
→ Payment  
→ Booking Confirmation  
→ View Booking History

### Host Flow

Login  
→ Host Dashboard  
→ Manage Homestays  
→ Manage Rooms  
→ Manage Prices and Availability  
→ View Customer Bookings  
→ Manage Reservations

## 5. Technical Challenges

- Checking room availability for selected dates
- Preventing double bookings
- Calculating the total price based on the number of nights
- Managing different permissions between customers and hosts
- Validating booking dates
- Maintaining accurate room and booking information
- Designing a simple and user-friendly interface
